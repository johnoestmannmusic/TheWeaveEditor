# AI-Assisted Development Disclosure
The Weave Explorer - John Oestmann
Last updated 23 Aug 26

As of 23 Aug 26, I have begun using GenAI to assist both in developing the programming of new features of The Weave Explorer, and to create an Editor to make it easier for me to add more content for this site.

I have not used GenAI to generate any audio or art assets used on this site.
In the future, I may use GenAI to help develop my own software that I can then use in my audio or art workflows. I intend to make tools I develop Open Source so others can use and adapt them to their own contexts.

If you would like to experience the website in its state before I involved AI in the development process, you can here: https://jomusic.neocities.org/PRE_AI/

You can download The Weave Editor software here: https://github.com/johnoestmannmusic/TheWeaveEditor?tab=readme-ov-file

You can read more about what changed my leaning from anti- to pro- AI, and my thoughts on how it integrates with Creative Process here: https://johnoestmannmusic.com/ai-building-exoskeletons/
